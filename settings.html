1. YouTube API key

The app reads channel uploads through the free YouTube Data API. The key is kept only in this browser.

How to get a key (about 5 minutes)
  1. Open Google Cloud Console and create a project (any name).
  2. Enable the YouTube Data API v3 for that project.
  3. Go to Credentials → Create credentials → API key.
  4. Recommended: edit the key → API restrictions → restrict it to YouTube Data API v3.
  5. Paste it below. The free quota (10,000 units a day) is plenty: a sync costs about 2–3 units per channel.

2. Import your subscriptions

Pick whichever is easiest. You can use more than one; duplicates are ignored.

Option A – Google Takeout file (no extra setup)

Go to takeout.google.com, click Deselect all, tick YouTube and YouTube Music, under “All YouTube data included” choose only subscriptions (and history if you want step 4). Export, unzip, then choose subscriptions/subscriptions.csv:

Option B – Paste channels

One per line: channel URLs, @handles or channel IDs (UC…).

Option C – Sign in with Google

Needs an OAuth client ID from the same Cloud project: Credentials → Create credentials → OAuth client ID → Web application, with as an Authorized JavaScript origin. Set up the OAuth consent screen as “External” and add yourself as a test user.

4. Import watch history (optional)

YouTube doesn't let other apps read your watch history or progress, so this app tracks progress when you play videos in its own player. To bring in what you've already watched on YouTube, import history/watch-history.html or .json from Google Takeout. Only videos currently marked unwatched are changed.

5. Backup

Your channels and watch progress live in this browser only. Export a backup to move them to another browser or PC.
